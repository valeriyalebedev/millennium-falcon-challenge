# millennium-falcon-challenge
Millenium falcon challenge solution

## Project structure

- **backend/** — Millennium Falcon onboard computer
- **frontend/** — C3PO (web UI)
- **cli/** — R2D2 (command line interface)

## Running the project 
You can start the entire project with 

```
npm run dev
```

This will start 
- Express Backend on http://localhost:3000
- Angular Frontend on http://localhost:4200

## Running the CLI Tool
The Commander CLI tool can be run manually with 

```
npm --prefix cli run dev
